## Integrity

The central research portfolio QA compares each declared resource against the current `main` Git tree. A size or Git blob SHA change requires an explicit update to `datapackage.json`.

This is a repository-integrity control, not a substitute for release-level cryptographic checksums in an archived snapshot.
