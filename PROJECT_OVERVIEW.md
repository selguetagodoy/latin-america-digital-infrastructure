# Project overview

Latin America Digital Infrastructure is a public comparative research repository covering eight benchmark markets: Argentina, Brazil, Chile, Colombia, Costa Rica, Mexico, Panama and Peru.

The current release combines five analytical layers: country benchmark indicators, cloud regions, Internet exchange points, submarine connectivity and operator market presence.

The main comparative dataset is `data/regional_benchmark_2026.csv`. It contains 27 variables spanning market scale, cloud availability, Internet exchange, resilience, energy, institutional conditions and digital readiness. Missing observations are left blank rather than estimated.

The repository uses market-level and country-level evidence. It does not publish customer information or non-public commercial inputs.

## Core datasets

- `data/regional_benchmark_2026.csv`
- `data/cloud_regions.csv`
- `data/ixps.csv`
- `data/submarine_cables.csv`
- `data/operator_country_presence.csv`
- `data/countries.csv`
