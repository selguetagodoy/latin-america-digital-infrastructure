# Data dictionary

## `data/countries.csv`

| Field | Description |
|---|---|
| `iso3` | ISO 3166-1 alpha-3 country code |
| `country` | Country name |
| `subregion` | Working geographic subregion |

## Planned datasets

Future releases are designed to add separate tables for cloud infrastructure, internet exchange points, submarine connectivity, data centers and public-policy indicators.

Each future table should include a country identifier, observation date or verification date, source reference and variables specific to that infrastructure category.
