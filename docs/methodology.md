# Methodology

## Purpose

This project provides a reproducible framework for comparing digital infrastructure across Latin American countries using public and verifiable information.

## Geographic scope

The initial reference table covers 20 sovereign states commonly included in Latin America. The scope can be expanded in later versions to support broader Latin America and Caribbean comparisons.

## Evidence principles

The project follows five rules:

1. Prefer original institutional or provider documentation.
2. Record when each source was checked.
3. Keep different infrastructure categories analytically separate.
4. Distinguish current observations from announced or planned developments.
5. Avoid estimates when a reliable public value is not available.

## Source hierarchy

Priority is given to official documentation, public-sector information and recognized technical registries. Industry databases and secondary publications may complement those sources when necessary.

## Updating the dataset

Each data release should identify its verification date and preserve enough source information for another researcher to reproduce the observation.

## Versioning

Major additions to country coverage, variables or methodological definitions should be documented in the repository history and release notes.
